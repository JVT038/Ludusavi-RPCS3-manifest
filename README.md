# Ludusavi-RPCS3-manifest
A Ludusavi manifest for RPCS3 games.
This allows Ludusavi to detect the save files for RPCS3 and make a backup of them.

# Usage
To use this manifest, do the following:
1. Add the raw manifest link to Ludusavi: https://github.com/JVT038/Ludusavi-RPCS3-manifest/raw/refs/heads/main/rpcs3.yaml
2. Add the path to RPCS3 to your roots;
  * Linux: `/home/<user>/.config/rpcs3` (for me personally)
  * Windows: `Documents/rpcs3` (allegedly, I haven't checked it myself)
  * MacOS: `Users/[Your Username]/Library/Application Support/RPCS3` (once again, I haven't checked this myself)
3. Click the refresh manifest button.
4. Now reload / rescan your games, and the RPCS3 games should appear!
